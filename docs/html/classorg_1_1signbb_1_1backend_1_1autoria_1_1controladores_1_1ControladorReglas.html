Descripción detallada

API REST del panel de reglas.

Una base de reglas pertenece a un grafo (grafo_raiz o un subgrafo) y agrupa las reglas que lo redirigen. Las operaciones que editan devuelven el borrador completo (BaseReglaDTO). Errores: 404 si el recurso no existe; 422 con ErrorAutoriaDTO si la edición no es válida o la base no se puede publicar; 409 si otra persona la cambió al mismo tiempo.
