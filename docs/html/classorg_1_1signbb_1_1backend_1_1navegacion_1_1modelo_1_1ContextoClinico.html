Descripción detallada

Conserva en memoria el grafo clínico y la base de reglas usados por el módulo de navegación.

MODIFICADO (cache): el contenido ya no se lee del classpath en el constructor. Se resuelve perezosamente en el primer uso a través de ResolvedorContenidoClinico (Redis como copia caliente, base de datos como fuente de verdad) y el TAD resultante queda en memoria para atender las peticiones: Redis nunca está en el camino de cada request, y la pereza garantiza que la siembra inicial (DatabaseInit) haya corrido antes de la primera resolución.
