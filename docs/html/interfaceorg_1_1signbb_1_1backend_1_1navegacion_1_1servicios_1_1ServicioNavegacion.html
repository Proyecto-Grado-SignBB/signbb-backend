Descripción detallada

API del módulo de navegación por el grafo clínico.

Expone el recorrido guiado como operaciones sin estado por petición: iniciar abre un recorrido y devuelve la primera pregunta; responder registra una respuesta y avanza un paso; consultar devuelve el estado actual.

MODIFICADO: se agrega la sobrecarga responder(String, List) para selección múltiple. La firma de un solo String no cambia.

Registra una o más respuestas marcadas a la vez para la misma pregunta (selección múltiple) y avanza el recorrido un paso.

Con una sola respuesta, se comporta exactamente igual que responder(String, String). Cuando hay más de una, se avanza hacia el nodo destino de mayor peso entre los candidatos (ver MotorNavegacion.paso).
