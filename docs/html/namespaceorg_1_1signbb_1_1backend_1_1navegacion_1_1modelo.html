record org.signbb.backend.navegacion.modelo.FotoNavegacion ( List< OpcionPendiente > cola,
List< PasoRuta > ruta,
Map< String, List< PasoRuta > > recomendaciones,
int siguienteOrden )

Copia inmutable del estado de navegación de una sesión en un instante: la cola de opciones pendientes, la ruta que se está siguiendo, las recomendaciones ya alcanzadas y el contador de orden de llegada.

Cada PasoRecorrido guarda la foto tomada antes de ejecutarse; deshacer el paso es restaurarla, lo que es más seguro que calcular qué entró y qué salió de la cola.

Parámetros
colaopciones pendientes, en el orden en que llegaron.
rutarecorrido real hasta la pregunta pendiente.
recomendacionesrecomendaciones alcanzadas (id del nodo → camino), en el orden en que se alcanzaron.
siguienteOrdennúmero de orden que recibirá la próxima opción encolada.

Guarda copias inmutables (el orden de las recomendaciones se conserva).

◆ OpcionPendiente()

record org.signbb.backend.navegacion.modelo.OpcionPendiente ( String idOrigen,
String condicion,
String idDestino,
int orden,
List< PasoRuta > camino )

Una opción que el cuidador marcó en una pregunta de selección múltiple pero que el recorrido todavía no ha seguido.

Se guarda en la cola de opciones pendientes de EstadoPaciente para retomarla cuando la rama que se está siguiendo termine en una recomendación.

La gravedad no se guarda: se calcula al ordenar, a partir del nodo destino (ver MotorNavegacion.ordenCola). Lo que sí se guarda es orden, el número de llegada, que desempata a igual gravedad (gana la más antigua) y que PriorityQueue de Java no garantiza por sí sola.

Parámetros
idOrigenpregunta en la que se marcó la opción.
condiciontexto de la opción marcada.
idDestinonodo al que lleva la opción.
ordennúmero de llegada a la cola (menor = más antigua).
caminorecorrido real hasta el destino, incluido el destino, para retomarlo como camino causal si esta opción se sigue.

Valida los ids y guarda una copia inmutable del camino.

record org.signbb.backend.navegacion.modelo.PasoRecorrido ( String idPregunta,
List< String > respuestas,
List< String > respuestasPrevias,
List< String > reglasMarcadas,
FotoNavegacion navegacionPrevia )

Una respuesta del cuidador tal como quedó anotada en la pila de pasos de EstadoPaciente: qué pregunta respondió, con qué opciones y qué reglas marcó como disparadas esa respuesta.

Es lo que hace falta para deshacerla sin reevaluar las reglas.

Parámetros
idPreguntapregunta respondida.
respuestasopciones marcadas en este paso.
respuestasPreviaslo que la pregunta tenía registrado antes de este paso (vacío si no tenía nada). Solo no es vacío si una regla "compuerta" llevó a una pregunta ya respondida; al deshacer se restaura.
reglasMarcadasreglas que este paso marcó como disparadas.
navegacionPreviafoto del estado de navegación (cola de opciones pendientes, ruta y recomendaciones) tomada antes de este paso; al deshacer se restaura. Es null en pasos guardados antes de existir la cola, que entonces no tocan la navegación al deshacerse.

Valida el id y guarda copias inmutables de las listas.

Paso sin foto de navegación (el formato anterior a la cola de opciones pendientes): al deshacerlo no se modifica la cola, la ruta ni las recomendaciones.

◆ PasoRuta()

record org.signbb.backend.navegacion.modelo.PasoRuta ( String idNodo,
String condicion )

Un paso del recorrido real del cuidador: el nodo al que llegó (por id) y la condición de la arista por la que llegó (cadena vacía para el primer nodo o para un salto de regla "compuerta").

A diferencia de PasoCausal, referencia el nodo por id y no por objeto, de modo que se puede guardar en la sesión (Redis) y deshacer al retroceder sin depender del grafo.

Parámetros
idNodoid del nodo alcanzado.
condicionopción elegida en la arista que llevó a ese nodo.

Valida el id y normaliza una condición nula a cadena vacía.

◆ ResultadoPaso()

record org.signbb.backend.navegacion.modelo.ResultadoPaso ( Estado estado,
Nodo preguntaActual,
NivelAlerta nivel,
Nodo destino,
List< ReglaClinica > razones,
List< PasoCausal > caminoCausal,
List< Recomendacion > recomendaciones )

Resultado de un paso del MotorNavegacion: la descomposición por pasos del Algoritmo 3 (una iteración del bucle while).

Cuando el recorrido sigue abierto (EN_CURSO) el resultado lleva la preguntaActual que debe responderse a continuación. Cuando el recorrido termina (FINALIZADO) lleva el nivel de alerta, el nodo destino alcanzado, las razones (reglas de nivel máximo que dispararon; vacío si el desenlace es NORMAL) y el caminoCausal reconstruido hasta el destino.

Cuando el recorrido termina sin alerta, recomendaciones trae todas las recomendaciones alcanzadas, cada una con su propio camino; en un resultado con alerta, o con el recorrido en curso, está vacía.

Estado de avance de un recorrido.

Falta responder al menos una pregunta más.

El recorrido terminó (por regla o por terminal del grafo).

Guarda una copia inmutable de las recomendaciones (nula equivale a vacía).

Resultado de un solo destino: sin lista de recomendaciones.

Construye un resultado EN_CURSO que espera la respuesta a pregunta.

Construye un resultado FINALIZADO con su nivel, destino, razones y camino causal.

Construye un resultado FINALIZADO que además lleva las recomendaciones alcanzadas durante el recorrido.

True si el recorrido terminó.
