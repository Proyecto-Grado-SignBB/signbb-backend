Descripción detallada

Implementación de ServicioRecorridos sobre la tabla recorrido.

MODIFICADO (CU10/CU11): usa el RepositorioSesion para saber si la sesión de un recorrido en curso venció (VENCIDO); "Mis recorridos" se muestra igual si Redis no responde. Al reiniciar, toma el CandadoRecorrido del recorrido, lo marca ABANDONADO y empieza uno nuevo dentro de una transacción. La sesión vieja se borra después de confirmar; si Redis falla en ese paso, la sesión caduca sola y la fila ya no deja seguirla.
