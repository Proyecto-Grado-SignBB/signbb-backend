Descripción detallada

Conversión bidireccional entre el TAD BaseReglas y su documento JSON BaseReglasJson.

La premisa de cada regla se expresa en forma normal disyuntiva (FND): una lista de casos (disyunción) donde cada caso es una lista de condiciones (conjunción). El nodoDestino de cada regla se persiste como id (referencia) y se resuelve contra el GrafoClinico correspondiente al reconstruir el TAD, fallando de inmediato si el nodo no existe en el grafo.
