record org.signbb.backend.observaciones.controladores.PreguntaDTO ( @Schema(description="Id del nodo pregunta") String id,
@Schema(description="Contenido de la pregunta") String texto,
@Schema(description="Etiquetas de las respuestas válidas") List< String > opciones,
@Schema(description="Si la pregunta tiene imágenes de apoyo") boolean tieneImagenes,
@Schema(description="Rutas de las imágenes; vacía si no tiene") List< String > imagenes,
@Schema(description="Tipo de interacción: SI_NO, SELECCION_UNICA o SELECCION_MULTIPLE") String tipoInteraccion )

Pregunta que el recorrido presenta al cuidador mientras está EN_CURSO.

opciones son las respuestas válidas: las etiquetas de las aristas salientes del nodo actual (p. ej. SI, NO, MAS_DE_24_HORAS).

tieneImagenes indica si esta pregunta tiene imágenes de apoyo (viene de metadata.archivos del grafo); imagenes trae sus rutas (metadata.src), vacía si tieneImagenes es false.

MODIFICADO: se agrega tipoInteraccion (SI_NO, SELECCION_UNICA o SELECCION_MULTIPLE) para que el frontend sepa qué pantalla renderizar sin tener que inferirlo del número de opciones. Se resuelve en RecorridoDTO#desde.

record org.signbb.backend.observaciones.controladores.RecorridoDTO ( @Schema(description="Id de la sesión de recorrido") String recorridoId,
@Schema(description="EN_CURSO o FINALIZADO") String estado,
@Schema(description="Pregunta actual; solo si el recorrido está en curso") PreguntaDTO pregunta,
@Schema(description="Desenlace; solo si el recorrido finalizó") ResultadoDTO resultado )

Vista REST de un recorrido de triaje.

Si estado es EN_CURSO, lleva la pregunta que debe responderse y resultado es null. Si es FINALIZADO, lleva el resultado y pregunta es null.

Construye el DTO a partir de un ResultadoPaso, resolviendo las opciones de la pregunta actual contra el grafo.

◆ ResultadoDTO()

record org.signbb.backend.observaciones.controladores.ResultadoDTO ( @Schema(description="Nivel de alerta resultante; NORMAL si no disparó reglas") String nivel,
@Schema(description="Id del nodo terminal") String destinoId,
@Schema(description="Contenido del nodo terminal") String mensaje,
@Schema(description="Ids de las reglas de nivel máximo que dispararon; vacío si NORMAL") List< String > razones,
@Schema(description="Secuencia de nodos y condiciones hasta el destino") List< PasoCausalDTO > caminoCausal,
@Schema(description="Recomendaciones alcanzadas; vacía si hubo alerta") List< RecomendacionDTO > recomendaciones )

Desenlace de un recorrido FINALIZADO.

nivel es el NivelAlerta resultante (NORMAL si se llegó a un terminal del grafo sin disparar reglas); destinoId y mensaje son el id y el contenido del nodo terminal; razones son los ids de las reglas de nivel máximo que dispararon (vacío si NORMAL); caminoCausal es la secuencia de nodos y condiciones hasta el destino; y recomendaciones son todas las recomendaciones alcanzadas, cada una con su propio camino. Solo viene con datos cuando el recorrido cierra sin alerta (ramas de selección múltiple que terminaron en recomendación, con o sin el cierre por el máximo de preguntas); con una alerta, o si no hay ninguna, es una lista vacía.
