Descripción detallada

Almacén de las sesiones de triaje en curso.

MODIFICADO (cache): pasa a interfaz cuya implementación es RepositorioSesionRedis (perfil docker), según el documento de diseño: las sesiones temporales de los padres viven en la caché distribuida para que las consultas sobrevivan reinicios del backend.

MODIFICADO (CU10/CU11): se agregan existe(String), para saber si una sesión ya venció sin tratarlo como error, y eliminar(String), para borrar la sesión de un recorrido que se reinicia.
