Descripción detallada

API REST del lienzo de autoría.

Las operaciones que editan devuelven el borrador completo (SubgrafoDTO). Errores: 404 si el subgrafo, el nodo o la respuesta no existen; 422 con ErrorAutoriaDTO si la edición no es válida o el borrador no se puede publicar; 409 si otra persona lo cambió al mismo tiempo.
