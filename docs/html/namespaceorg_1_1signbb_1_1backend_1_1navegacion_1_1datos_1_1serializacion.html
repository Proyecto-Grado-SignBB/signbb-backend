record org.signbb.backend.navegacion.datos.serializacion.GrafoClinicoJson ( Grafo graph)

Documento JSON de un grafo clínico: el mismo formato de intercambio de static/ejemplo_grafo.json, usado además como formato persistido en la columna estructura de GrafoClinicoEntity.

Los nodos se almacenan una sola vez (indexados por id) y las aristas referencian nodos por id, de modo que la estructura interna queda inspeccionable (por SQL sobre el jsonb) y no se duplican datos entre elementos que apunten a los mismos nodos. El estado de navegación (bloqueado) y los umbrales de peso (configuración de uso del TAD) no forman parte del documento.

Sección graph del documento.

Nodo del grafo: label es el contenido y el resto vive en metadata.

Metadatos usados para reconstruir el TAD Nodo. peso y archivos usan wrappers para tolerar campos ausentes en el JSON (Jackson 3 rechaza null sobre primitivas por defecto). tipoInteraccion es el override opcional de interacción (SI_NO, SELECCION_UNICA, SELECCION_MULTIPLE): ausente/null significa que RecorridoDTO lo infiere de las opciones del nodo.

Arista: referencia los nodos por id, nunca embebe el objeto Nodo.
