Descripción detallada

Impide arrancar en producción con los valores de ejemplo del repositorio o con la documentación de la API abierta.

El entorno se indica con SIGNBB_ENTORNO (signbb.entorno): desarrollo (por defecto) o produccion. En producción, si el secreto del JWT, la contraseña del supervisor inicial o las claves de Silo siguen valiendo lo mismo que en desarrollo, o si Swagger y /v3/api-docs siguen activos (SIGNBB_DOCS_ACTIVAS distinto de false), la aplicación no arranca y el mensaje dice qué variables corregir (nunca muestra los valores). Un entorno con cualquier otro texto también impide arrancar, para que un error de escritura no deje la revisión apagada sin avisar.

La revisión ocurre al construir este componente, antes de que se siembre el supervisor inicial o se atienda alguna petición.
