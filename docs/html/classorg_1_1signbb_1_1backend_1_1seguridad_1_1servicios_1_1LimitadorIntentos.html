Descripción detallada

Límite de intentos por correo/cuenta, persistido en PostgreSQL.

El alcance actual no limita por IP ni de forma global: solo por cuenta. El ingreso cuenta los fallos y borra el contador tras un ingreso correcto; el registro cuenta todos los intentos para una misma cuenta. La clave que se guarda es un hash del correo normalizado, no el correo en claro.

Al vivir en PostgreSQL, una caída de Redis no desactiva el límite. Si la base de datos no responde, el ingreso tampoco puede validar la cuenta.
