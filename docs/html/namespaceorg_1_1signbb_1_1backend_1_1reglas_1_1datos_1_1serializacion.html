record org.signbb.backend.reglas.datos.serializacion.BaseReglasJson ( Map< String, ReglaJson >  rules)

Documento JSON de una base de reglas: el mismo formato de intercambio de static/ejemplo_reglas.json, usado además como formato persistido en la columna estructura de BaseReglasEntity.

Cada regla referencia su nodoDestino por id (nunca embebe el nodo): el destino se resuelve contra el grafo clínico correspondiente al reconstruir el TAD, fallando de inmediato si la referencia queda colgando. El nivel se mantiene como cadena para preservar el contrato de los parsers (valores inválidos lanzan IllegalArgumentException).

condiciones se conserva como JsonNode porque la premisa se expresa en forma normal disyuntiva (FND): un arreglo de casos, donde cada caso es un arreglo de condiciones. El formato plano (arreglo de condiciones) se acepta como un único caso por compatibilidad; la expresión se interpreta y se reconstruye en BaseReglasMapper.

Regla clínica en formato serializable.
