Modelo de reglas (TAD)

TAD ReglaClinica (ReglaClinicaTest)

La premisa es una fórmula en forma normal disyuntiva (FND): un caso es una conjunción (AND) de condiciones y la regla se satisface si al menos un caso se cumple (OR). El constructor plano (lista de Condicion) equivale a un único caso (AND). Se verifica que:

  • una regla sin condiciones o con componentes nulos se rechaza;
  • condicionesCumplidas exige todas las condiciones del caso.

TAD BaseReglas (BaseReglasTest)

Colección indexada por idRegla. Se verifica el alta y la baja y que reglasActivadas devuelve solo las reglas cuya premisa se satisface en el estado.

Evaluación abstracta (EvaluacionReglasAbstractaTest)

Conserva los dos casos que no cubren las otras suites, con datos abstractos (resp1/op1/op2/op3) y los TADs EstadoPaciente y Nodo simulados con Mockito:

  • varios casos (OR) armados con ReglaClinica.conCasos;
  • varias opciones de la misma pregunta combinadas con AND (selección múltiple).

Servicio de inferencia y mapeo JSON

Servicio de inferencia (ServicioReglasImplTest)

Implementa la fase de resolución de conflicto del motor de reglas (Algoritmo 3 del diseño): cuando varias reglas se activan a la vez, gana el nivel más severo (NORMAL < CONSULTAR_MEDICO < URGENCIA); entre las del nivel máximo se combinan todas como razones y el destino es el de mayor peso (el signo más crítico). Se cubre:

  • dos reglas del mismo nivel que combinan sus razones;
  • ninguna regla activa → resultado NORMAL sin destino;
  • niveles mixtos → gana el más severo;
  • empate de nivel con destinos de distinto peso → gana el de mayor peso.

Mapeo JSON (BaseReglasMapperTest)

Verifica la ida y vuelta entre el TAD BaseReglas y el documento JSON de intercambio, que conserva la forma normal disyuntiva en condiciones:

  • reconstrucción fiel desde el contenido compuesto del sistema (tamaño, nombre, nivel, destino y condiciones de cada regla);
  • el nodoDestino se serializa por id (nunca se embebe el nodo);
  • un nodoDestino que no existe en el grafo se rechaza al reconstruir.

Cómo ejecutarlas

./mvnw test -Dtest='org.signbb.backend.reglas.**'

No requieren PostgreSQL ni Redis.
