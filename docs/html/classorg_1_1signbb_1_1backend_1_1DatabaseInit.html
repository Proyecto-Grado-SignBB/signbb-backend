Descripción detallada

Inicialización de la base de datos: siembra el grafo clínico y la base de reglas de ejemplo (static/ejemplo_grafo.json y static/ejemplo_reglas.json) cuando sus tablas están vacías.

Antes de guardar cada documento se reconstruye el TAD con los parsers, de modo que solo se persisten datos válidos (referencias colgantes, niveles inválidos o aristas rotas fallan aquí). El documento se guarda tal cual viene del JSON para conservar los metadatos de presentación (autor, categorías) que el TAD no almacena, completando el nodoInicial explícito si el archivo no lo trae. La siembra es idempotente: si las tablas ya tienen filas, no hace nada.
