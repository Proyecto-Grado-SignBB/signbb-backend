Descripción detallada

TAD EstadoPaciente (Sección 4.2 del documento de diseño).

Representa una sesión de triaje en curso: las respuestas del padre a las preguntas del grafo y el puntaje acumulado. No contiene lógica de inferencia — solo almacena y consulta.

Se usa LinkedHashMap para conservar el orden de inserción de las respuestas (mismo comportamiento determinista que el dict de Python).

MODIFICADO (multi-respuesta): una pregunta de selección múltiple puede registrar varias respuestas para el mismo nodo. registrarRespuesta mantiene el contrato histórico (sobrescribe con una sola), mientras que registrarRespuestas guarda todas las opciones marcadas; las reglas las consultan con getRespuestas. También se recuerdan las reglas ya disparadas (marcarReglaDisparada) para que el encadenamiento hacia adelante no vuelva a activarlas cuando una regla redirige el recorrido.
