Descripción detallada

Formato propio del lienzo de autoría: el documento del borrador, sus nodos y respuestas, y los avisos que se le muestran al médico.

No depende de Spring ni de la base de datos.

record org.signbb.backend.autoria.modelo.BorradorRegla ( String nombre,
String descripcion,
List< Caso > casos,
NivelAlerta nivel,
String nodoDestino )

Regla de un borrador de base de reglas, tal como la edita el médico.

Reutiliza el TAD del dominio: los Caso son la forma normal disjuntiva (OR de casos, AND dentro de cada caso) y nodoDestino referencia un nodo del grafo al que pertenece la base, por id local (el compositor lo prefija al publicar).

Parámetros
nombretexto descriptivo de la regla
descripcionexplicación para el médico, opcional
casosFND de la regla; puede estar vacía mientras se edita
nivelseveridad al dispararse; NivelAlerta#NORMAL no es válido para una regla
nodoDestinoid del nodo destino, o null mientras se edita

Normaliza los casos ausentes a una lista vacía inmutable.
