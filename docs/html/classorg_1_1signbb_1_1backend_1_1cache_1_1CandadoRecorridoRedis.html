Descripción detallada

Candado por recorrido en Redis (signbb:candado:recorrido:<id>).

Se toma con SET NX y caduca solo a los 10 segundos, para que una caída del servidor no deje el recorrido bloqueado. Cada toma guarda una ficha única y solo quien la tiene puede soltarlo (así una operación lenta, cuyo candado ya caducó, no suelta el de otra). Si Redis no responde, falla con CacheNoDisponibleException (503), igual que las sesiones.
