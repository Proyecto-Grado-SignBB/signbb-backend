Descripción detallada

Fachada del módulo de autoría que usa la API REST.

Las operaciones que editan devuelven el borrador completo. Un id inexistente lanza RecursoNoEncontradoException (404); una edición no válida, EdicionInvalidaException (422). Quién puede leer o editar cada borrador lo revisa GuardiaAutoria en el controlador, antes de llamar aquí.

◆ despublicar()

SubgrafoDTO org.signbb.backend.autoria.servicios.ServicioAutoria.despublicar ( Long id)

Despublica un subgrafo: las cuidadoras que empiecen un recorrido nuevo ya no lo ven y el borrador vuelve a BORRADOR con el lienzo intacto.

También retira su base de reglas y devuelve el borrador de reglas a BORRADOR, conservando el documento. Los recorridos que ya estaban en curso terminan con la versión con la que empezaron.

Excepciones
EdicionInvalidaExceptionsi el subgrafo no está publicado (422)
ContenidoInvalidoExceptionsi el contenido restante no es válido, por ejemplo si era el único publicado (422)
